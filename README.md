<details>
<summary><b>More about Project Nexus</b></summary>
<br>

A multi agent simulation engine designed to be different from typical RAG-based agent platforms:

- Persistent typed belief states (Pydantic models) evolving across simulation ticks
- Per actor information asymmetry enforced via MCP server access controls
- Emergent behavior from agent to agent interaction, not retrieval
- Build order: simulation core → observability → MCP servers → UI → ML modules

**Stack:** LangGraph · MCP · LangSmith

</details>
